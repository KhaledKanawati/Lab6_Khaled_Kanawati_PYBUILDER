# Lab 6 submission

`calculator_Khaled_Kanawati` is the graded calculator exercise. `my_python_project` follows the later PyBuilder and Makefile submission section. `makefile_example` contains the separate optional Makefile exercise.

Use Python 3.11 or newer. Install PyBuilder with `python -m pip install pybuilder==0.13.20`, then run `pyb run_unit_tests` and `pyb` inside the calculator folder. For `my_python_project`, install GNU Make and run `make all`, or run the Makefile commands separately. The optional example uses `make install`, `make test`, `make lint`, and `make package`.
